# Roadmap (Train A focus)

Full milestone detail was designed in architecture planning. Summary:

| Milestone | Outcome                                            |
| --------- | -------------------------------------------------- |
| **M0**    | Foundation: monorepo, CI, Docker, health (current) |
| **M1**    | Tenancy + Auth + RBAC                              |
| **M2**    | Materials & print profiles                         |
| **M3**    | Uploads + geometry analysis                        |
| **M4**    | Pricing + quotes                                   |
| **M5**    | Customers + orders                                 |

Later: inventory, printers, notifications, analytics, portal, SaaS billing, AI/ML.

Each milestone must be independently deployable and testable.
