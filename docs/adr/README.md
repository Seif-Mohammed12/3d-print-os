# Architecture Decision Records

Store ADRs here as `NNNN-title.md` (e.g. `0001-modular-monolith.md`).

Template:

1. **Status** — Proposed | Accepted | Superseded
2. **Context** — Problem and forces
3. **Decision** — What we chose
4. **Consequences** — Pros, cons, follow-ups

Write an ADR before changing tenancy, auth, messaging, payments, data strategy, or extracting a service.
